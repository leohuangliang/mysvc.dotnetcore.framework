# 后端架构设计专业知识

## 系统架构模式

### 分层架构(Layered Architecture)
- **表示层(Presentation Layer)**：API控制器，用户界面
- **业务逻辑层(Business Layer)**：业务规则，领域逻辑
- **数据访问层(Data Access Layer)**：数据持久化，仓储模式
- **基础设施层(Infrastructure Layer)**：外部服务，技术实现
- **跨层关注点**：日志、安全、缓存、事务管理

### 洋葱架构(Onion Architecture)
- **领域核心**：实体、值对象、领域服务
- **应用服务层**：用例实现，业务流程编排
- **基础设施层**：数据访问、外部服务适配器
- **依赖倒置**：内层不依赖外层，通过接口解耦
- **测试友好**：核心业务逻辑易于单元测试

### 六边形架构(Hexagonal Architecture)
- **应用核心**：业务逻辑和规则
- **端口(Ports)**：应用与外部世界的接口
- **适配器(Adapters)**：端口的具体实现
- **主适配器**：驱动应用的外部系统(Web API、消息队列)
- **从适配器**：被应用驱动的外部系统(数据库、外部服务)

## 微服务架构设计

### 服务拆分策略
- **业务能力拆分**：按业务功能划分服务边界
- **数据拆分**：每个服务拥有独立的数据存储
- **团队拆分**：康威定律，组织结构影响系统架构
- **技术栈独立**：服务可选择最适合的技术栈
- **独立部署**：服务可独立发布和扩展

### 服务间通信
- **同步通信**：HTTP REST API、gRPC
- **异步通信**：消息队列、事件驱动
- **服务网格**：Istio、Linkerd流量管理
- **API网关**：统一入口、认证、限流、监控
- **服务发现**：动态服务注册和发现

### 数据管理模式
- **数据库per服务**：每个服务独立数据库
- **Saga模式**：分布式事务管理
- **CQRS**：命令查询职责分离
- **事件溯源**：通过事件重建状态
- **最终一致性**：分布式系统数据一致性

## 高可用架构设计

### 容错设计
- **断路器模式**：防止级联故障
- **重试机制**：临时故障恢复
- **超时控制**：避免资源耗尽
- **降级策略**：核心功能保障
- **隔离机制**：故障影响范围控制

### 负载均衡
- **水平扩展**：增加服务实例数量
- **负载均衡算法**：轮询、权重、最少连接
- **健康检查**：自动剔除故障实例
- **会话亲和性**：有状态服务处理
- **地理分布**：就近访问优化

### 缓存架构
- **多级缓存**：浏览器、CDN、应用、数据库缓存
- **缓存策略**：Cache-Aside、Write-Through、Write-Behind
- **缓存一致性**：更新策略和失效机制
- **缓存穿透防护**：布隆过滤器、空值缓存
- **缓存雪崩防护**：随机过期时间、熔断机制

## 数据架构设计

### 数据存储选择
- **关系型数据库**：ACID特性，复杂查询
- **NoSQL数据库**：高并发，灵活模式
- **时序数据库**：监控数据，IoT数据
- **搜索引擎**：全文搜索，复杂查询
- **图数据库**：关系网络，推荐系统

### 数据分片策略
- **水平分片**：按数据范围分布
- **垂直分片**：按功能模块分离
- **一致性哈希**：分布式数据分布
- **分片键选择**：均匀分布，避免热点
- **跨分片查询**：聚合查询优化

### 数据同步和复制
- **主从复制**：读写分离，数据备份
- **主主复制**：多写入点，冲突解决
- **异步复制**：性能优化，最终一致性
- **同步复制**：强一致性，性能影响
- **数据迁移**：在线迁移，零停机时间

## 安全架构设计

### 认证和授权
- **多层认证**：网关、服务、数据层认证
- **零信任架构**：不信任任何网络位置
- **权限模型**：RBAC、ABAC权限控制
- **令牌管理**：JWT、OAuth 2.0、刷新机制
- **单点登录**：统一身份管理

### 数据安全
- **传输加密**：TLS/SSL协议
- **存储加密**：数据库加密，文件加密
- **密钥管理**：密钥轮换，安全存储
- **敏感数据脱敏**：日志脱敏，测试数据脱敏
- **审计日志**：操作追踪，合规要求

### 网络安全
- **防火墙配置**：网络访问控制
- **DDoS防护**：流量清洗，限流机制
- **API安全**：限流、防重放、输入验证
- **内网隔离**：网络分段，最小权限
- **安全扫描**：漏洞检测，依赖检查

## 性能架构优化

### 系统性能优化
- **异步处理**：非阻塞I/O，提高吞吐量
- **连接池管理**：数据库连接复用
- **资源池化**：对象复用，减少GC压力
- **批处理优化**：减少网络往返次数
- **预加载策略**：提前加载热点数据

### 数据库性能优化
- **索引优化**：查询性能提升
- **查询优化**：SQL调优，执行计划分析
- **分区表**：大表性能优化
- **读写分离**：负载分担
- **数据归档**：历史数据管理

### 监控和诊断
- **应用性能监控(APM)**：请求追踪，性能分析
- **基础设施监控**：CPU、内存、网络、磁盘
- **业务指标监控**：关键业务指标追踪
- **日志聚合**：集中日志管理和分析
- **告警机制**：异常情况及时通知
